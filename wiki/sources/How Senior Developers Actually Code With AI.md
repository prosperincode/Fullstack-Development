## Summary

The clipping presents a controlled AI coding workflow for building production features in an existing codebase: define the idea, document product context, create a high-quality prompt, generate and review a plan, break the work into small phases, implement, test, review diffs, debug from evidence, and use AI review tools as an additional review layer.
