# How To Scientifically Design Addictive Apps

Original clipping: [YouTube](https://www.youtube.com/watch?v=yBpv5rZoBjA)  
Author: Tim Gabe  
Published: 2026-04-17  
Processed: 2026-05-10

## Summary

The clipping describes three retention mechanisms: a craving machine using controlled surprise and variable rewards, an infinite game using streaks and loss aversion, and an invisible scoreboard using social comparison and visible status.

## Verified Updates

- The clipping's structure overlaps with the Hook Model: trigger, action, variable reward, and investment.
- The techniques can improve habit formation, but they also create ethical risk. FTC guidance treats manipulative design patterns that trick or trap users as dark patterns.
- In this wiki, these patterns should be framed as retention design tools with explicit ethical constraints, not as a mandate to create compulsive behavior.
